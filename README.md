# From Representation to Governance
## 3D Geovisualisation as Decision Infrastructure in Urban Digital Twins

A Three-Layer Evaluation Framework applied to four international urban digital twin deployments.
[View Story Map →](https://arcg.is/DrX4G0)

## Framework
Layer 1: Representation — Is the model technically reliable?
Layer 2: Interpretation — Do users understand it correctly?
Layer 3: Governance — Does it measurably improve decisions?

## Case Studies
Nottingham · Bradford (Virtual Bradford) · Virtual Singapore · Helsinki 3D

## Primary Data
GPS positional accuracy field experiment, University of Nottingham campus, 2026
(Open space: 2m | Tree canopy: 11m | Enclosed building: 26m)

## Key Finding
A 3D city model is not automatically a digital twin.
Visualisation is not governance.
